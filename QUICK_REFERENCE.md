# ⚡ Quick Reference - Flatten Build Commands

## TL;DR - 30 Second Setup

```bash
# Step 1: Install dependencies
npm install --save-dev rollup @rollup/plugin-node-resolve @rollup/plugin-commonjs

# Step 2: Run the script
node flatten-build-enhanced.js

# Step 3: Open the result
# Windows: start offline_ready_site\index.html
# Mac/Linux: open offline_ready_site/index.html
```

Or just run:
```bash
node setup.js 2
```

---

## All Commands

### Installation Commands

```bash
# Option 1: Install everything at once
npm install --save-dev rollup @rollup/plugin-node-resolve @rollup/plugin-commonjs

# Option 2: Install one at a time
npm install --save-dev rollup
npm install --save-dev @rollup/plugin-node-resolve
npm install --save-dev @rollup/plugin-commonjs

# Option 3: Using yarn
yarn add --dev rollup @rollup/plugin-node-resolve @rollup/plugin-commonjs

# Check what's installed
npm list rollup @rollup/plugin-node-resolve @rollup/plugin-commonjs
```

### Build Commands

```bash
# Basic version (minimal logging)
node flatten-build.js

# Enhanced version (recommended, more features)
node flatten-build-enhanced.js

# Auto-setup version (installs deps + runs script)
node setup.js 2

# With debug logging
DEBUG=1 node flatten-build-enhanced.js
```

### Verify Output

```bash
# List generated files
ls offline_ready_site/
# or on Windows:
dir offline_ready_site\

# Check file size
ls -lh offline_ready_site/index.html
# Windows: Get-Item offline_ready_site\index.html | Select-Object Length
```

### Open Generated File

```bash
# Windows
start offline_ready_site\index.html

# Mac
open offline_ready_site/index.html

# Linux
xdg-open offline_ready_site/index.html

# Or just double-click in file explorer!
```

### Troubleshooting Commands

```bash
# Verify Node.js version (need 14+)
node --version

# Verify npm version
npm version

# Clear npm cache (if installation fails)
npm cache clean --force

# Reinstall dependencies fresh
rm -rf node_modules
npm install --save-dev rollup @rollup/plugin-node-resolve @rollup/plugin-commonjs

# Check if dist folder exists and has content
ls dist/
ls dist/assets/

# Run production build first (if needed)
npm run build

# Check file protocol path
node -e "console.log('file:///' + require('path').resolve('offline_ready_site/index.html').replace(/\\\\/g, '/'))"
```

## npm Scripts to Add to package.json

```json
{
  "scripts": {
    "build": "vite build",
    "preview": "vite preview",
    "flatten": "node flatten-build.js",
    "flatten:enhanced": "node flatten-build-enhanced.js",
    "build:offline": "npm run build && npm run flatten:enhanced",
    "setup": "node setup.js 2"
  }
}
```

Then use:
```bash
npm run build:offline    # Build + flatten in one command
npm run flatten:enhanced # Just flatten (if dist already exists)
npm run setup            # First-time setup
```

## Performance Optimization

```bash
# Build without source maps (smaller file)
# Edit vite.config.js, set: build.sourcemap = false
npm run build
npm run flatten:enhanced

# Compress the final output (if serving via HTTP)
gzip offline_ready_site/index.html

# Check resulting size
ls -lh offline_ready_site/
```

## Troubleshooting Quick Links

| Error | Fix |
|-------|-----|
| `Cannot find module 'rollup'` | `npm install --save-dev rollup` |
| `dist directory not found` | Run `npm run build` first |
| `No JavaScript files found` | Check `dist/assets/` has `.js` files |
| Blank white page | Check browser console (F12), look for errors |
| Module not found errors | Normal, check specific module in console |
| CORS errors | You should be using `file://` protocol, not `http://` |
| File too large | Normal - use dist/ version on slow connections |
